# MVSR – Moderne Verfahren zur sensorbasierten Roboterregelung

Hausübungen (FH Technikum Wien, Master Robotic Engineering), umgesetzt in Python mit OpenCV.

- `Homework1/` – Grundlagen OpenCV, Kamerakalibrierung

- `Homework3/` – Visual Servoing (IBVS), siehe `Homework3/README.md`
